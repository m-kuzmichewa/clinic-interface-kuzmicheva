# Запись пациентов на приём

Интерфейс на JavaScript для управления записью пациентов. 

## Как запустить
Откройте файл `index.html` в любом современном браузере (или используйте расширение Live Server в VS Code).

## Реализованные возможности
- **Добавление записи:** раздельные поля для Фамилии, Имени и Отчества.
- **Специальности:** выбор врача из выпадающего списка.
- **Экспорт в CSV:** скачивание всех записей в файл (с поддержкой кириллицы для корректного открытия в Excel).
- **Умный поиск:** поиск совпадений одновременно по ФИО и по специальности.
- **Таблица:** результаты поиска выводятся в аккуратную HTML-таблицу.
- **Сохранение:** данные не пропадают при перезагрузке страницы благодаря `localStorage`.
